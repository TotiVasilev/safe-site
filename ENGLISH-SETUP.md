# TETRAEDAR English website

Bulgarian is edited in Decap CMS. The English translations are stored under `content/en/` and generated with the free Argos Translate engine. No visitor-time translation API is used.

## Setup

1. Copy the updated files into the project without changing the directory structure.
2. Commit and push.
3. In GitHub Actions, run **Translate all CMS content to English** manually once. The workflow will commit generated English files.
4. Future pushes changing `content/*.json` or CMS markdown content will trigger the translation workflow automatically.
5. After GitHub commits translations, Cloudflare will build the English routes.

The original homepage-only pilot workflow is still available but is no longer needed.

## Important limitations

- English translations generated by Argos must be reviewed for technical safety terminology and the privacy policy.
- The English product catalog and service pages reuse the Bulgarian component layout; some interface labels inside components are still Bulgarian.
- Translation of product descriptions depends on the content being in markdown frontmatter `description`; URLs, models and numeric specifications remain unchanged.
- The site uses Next.js static export; new content is available only after GitHub Actions commits translations and the deployment rebuilds.
- If the translation workflow fails, existing saved English content remains in place.
- The generated English pages fall back to Bulgarian content for missing translation files; check the first workflow run before publishing the EN switch.

## Local translation

Install Python 3.11 and run:

```sh
pip install argostranslate==1.9.6 PyYAML==6.0.2
python scripts/translate-all.py
```
